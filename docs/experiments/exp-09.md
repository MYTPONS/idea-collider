# exp-09 按近域类型收窄

## 目的

exp-08 遗留问题:一条形态配 6 个约束对,因为机制只按轴匹配,同一轴上的近域约束被一视同仁。

## 实现

- 机制加 `targets` 字段,标它能解的近域类型:禁写、绑定、改写、承诺、打扰、断裂
- `near_style` 从近域文本推断类型;AI 接入层的六条映射到同一套类型(上游不稳定→断裂、成本→承诺、漂移→改写、身份→承诺、不留存→断裂、对公→绑定)
- 组合时若机制 targets 非空且近域类型不在其中,跳过

## 结果

| | 收窄前 | 收窄后 |
|---|---|---|
| 第一组候选 | 109 | 32 |
| 第一组空白 | 15 | 11 |
| 第二组候选 | 108 | 48 |
| 第二组空白 | 16 | 15 |
| 单条形态配的约束对 | 6 | 1 到 3 |

第一组推荐:

| 形态 | 撞的约束 |
|---|---|
| 账户内便携格式 | a2×b1 / a6×b1 |
| 只读快照 | a1×b1 / a4×b1 |
| 导出 | a2×b1 / a4×b1 / a6×b1 |
| 改写前时间锁 | a3×b3 / a3×b4 / a6×b4 |
| 撤销 | a3×b2 / a4×b2 / a4×b3 / a4×b4 |

第二组推荐:

| 形态 | 撞的约束 |
|---|---|
| 重放(单条) | a3×b2 |
| 时间锁 | a1×b4 等 5 对 |
| 即焚 | a5×b3 / a5×b4 |
| 只读快照 | a2×b1 / a4×b1 |
| 便携格式 | a1×b1 等 4 对 |

## 结论

- 收窄生效:形态和约束对一一对上,报告信息量上来了
- 代价是候选数掉了三分之二,漏掉的可能里有一部分本来切题
- 近域类型是手工映射,换新域要重标
