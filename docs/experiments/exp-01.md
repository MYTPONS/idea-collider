# 实验 01

日期:2026-11-04
方式:手工,未使用系统
参与:一顿操作,咖啡,一支笔

## 领域对

近域 A:AI 接入层(国模 API 中转、自托管部署、多上游路由)。实验者熟悉,客户碰得到。

远域 B:殡葬服务。选它的理由是约束极硬且几乎未被 AI 语料反复消化。

## 约束抽取

### A 的硬约束

- a1 上游可用性是随机的。账号、额度、限速、价格会在无通知的情况下变化。任何以单一上游为前提的设计都会周期性失效。
- a2 单位成本随用量线性增长。小体量玩家没有规模效应,毛利结构注定趋向于零。
- a3 模型行为在版本之间漂移。同一输入在两周后可能给出不同结果,且变化不可预知。
- a4 客户无法独立验证响应来自哪个具体模型。
- a5 请求内容可能包含客户商业数据,但客户要求不留存。
- a6 对公收款需要主体、发票、合同。个人身份无法满足。

### B 的硬约束

- b1 时间窗刚性。多数环节必须在 24 至 72 小时内完成,超时不可挽回。
- b2 服务半径刚性。必须本地现场,跨区域无意义。
- b3 不可试用、不可退换、不可比价。决策在情绪与忌讳下完成,理性比较被压制。
- b4 供给侧高度碎片化。主体多为夫妻店,无 IT 能力,无标准化流程。
- b5 获客几乎只靠口碑与熟人转介。信息不对称极端。
- b6 资质与属地监管构成准入门槛。

## 交集

逐对检查 36 组,有实质交互的 9 组。

| 组合 | 必须同时满足什么 | 候选形态 | 判定 |
|---|---|---|---|
| a1 × b1 | 上游随时失效,而完成窗口不可延 | 断上游仍能跑的边缘推理,本地小模型兜底 | 砍:客户不可达 |
| a1 × b5 | 上游随时失效,而口碑是唯一获客 | 故障对外不可见,静默降级 | 砍:客户不可达 |
| a3 × b1 | 模型版本漂移,而流程必须可复现 | 模型版本冻结 + 结果留痕 | 砍:客户不可达 |
| a4 × b5 | 无法验证模型身份,而信息不对称极端 | 可验证的模型身份:每次响应带指纹、可追溯、可对外证明 | **存活** |
| a5 × b2 | 不留存数据,而必须本地处理 | 本地推理一体机,数据不出机器 | 砍:客户不可达 |
| a6 × b4 | 需要发票与合同,而供给侧是无 IT 能力的个体 | 给个体从业者套合规外壳 | 砍:法律上等同代持资质 |
| a2 × b3 | 成本线性,而市场不可比价 | 在不可比价市场正价销售 | 砍:是定价策略,不是产品形态 |
| a1+a4 × b5 | 上游随机失效且客户无法验证,而一次故障失去全部口碑 | 多上游自动切换 + 每次切换留痕 + 切换对客户可证明 | **存活** |
| a3 × b6 | 版本漂移,而资质要求可追责 | 面向有资质行业的结果可追溯服务 | 砍:客户不可达 |

## 存活候选

两条存活候选实际是同一个东西的两面:**给"卖 AI 接入"的人提供可验证、可切换、可留痕的接入层**。

第一维,现在有人做吗。New API、one-api、LiteLLM 做多上游切换和日志,但它们做的是路由和计费,不做"可向第三方证明这次调用用的是哪个模型"。切换日志是给自己看的,不是给客户看的。

第二维,做的人卡在哪。卡在没人要求。做中转的人默认客户不会追问,而客户也确实追问不了,因为拿不到可验证的凭据。

第三维,两周能出什么。第一版砍到只剩:每次响应返回模型指纹(上游返回的 model 字段 + 上游 provider 标识 + 请求耗时 + 响应头摘要),拼成一条可外传的凭据。不做密码学签名,不做第三方验证,只做"可出示"。两天能出。

第四维,第一个客户是谁。成品号市场和共享 key 池的运营者,以及做 API 中转的小团队。具体来源是那些把 New API 部署出来对外卖的人,他们在同样的圈子里,抱怨过"客户怀疑我偷换成便宜模型"。

## 方法学警告

这次实验被污染了。

实验者熟悉近域 A,抽约束时下意识地把 A 的约束往"接入层可卖钱"的方向引导。结果两条存活候选本质同质,而且都落在实验者现有能力范围内。

污染不影响结论可用性,但影响结论的新鲜度:它没有撞出实验者原本想不到的东西,只是把他已经隐约想到的东西形式化了。

要检验机制是否真能产生意外,必须换一组近域为实验者不熟悉的领域对。下一轮建议:A 换成殡葬(现在它是远域,已经抽过约束,可以直接当近域用),B 换一个全新的远域,比如农机跨区作业或眼科验光。

## 本轮结论

机制跑通。36 组交集里 9 组有实质内容,过滤后剩 2 条(且同质)。命中率 2/9,低于预期的 1/100,因为约束抽得太干净、候选数量太少。正式跑必须把候选量提到三位数,否则过滤器的价值体现不出来。

收获最大的一条规则是设计文档里的第一条:远域只借约束,客户永远从近域来。这一条是砍掉四个最有趣候选的直接原因。
