# 实验 05

日期:2026-11-08
方式:手工(媒体采样 + 法规约束)
目的:把已存在的记忆/主动助理产品当近域,检验"想法被别人先做"是稀缺事实还是采样偏差,并求这些产品没有覆盖的约束

## 领域对

近域 A:机器之心 SOTA 收录的「记忆 / 主动助理」产品面。取四个:阿里云 Memory(A5 同栏)、A5 主动式个人助理、Claude Duet、Replit Monitoring Agent。

选它算近域的理由:客户碰得到(做 AI 接入的中转商能直接对接这些 API),能判断真假(有产品名、有接入方式、有公开描述)。来源是机器之心首页于 2026-11-08 的收录条目,不是二手转述。

远域 B:个人信息保护合规,即数据主体对个人信息的查阅、复制、更正、删除权。

选它的理由:这是法规强加的硬约束,违反有法律后果;来源可查,不靠回忆;和近域产品的「自动提取、平台绑定、动态更新」正面相撞。

## A 的硬约束

- a1 记忆由系统自动提取写入,用户不参与写入过程。
- a2 记忆绑定账户与平台,跨平台不通用。
- a3 记忆是「动态更新」的,但更新由系统发起,没有用户显式更正的一等入口。
- a4 对外承诺的是「少问几遍」,不是「你能查、能改、能带走」。
- a5 主动助理会主动建议、主动做事,打扰是默认副作用。
- a6 能力依赖终身上下文,用越久越粘。

以上六条均来自产品公开描述,不是推测。

## B 的硬约束

- b1 个人有权查阅、复制其个人信息。
- b2 个人有权请求更正其个人信息。
- b3 个人有权请求删除其个人信息。
- b4 处理者须响应请求,不得以「没有这个功能」为由拒绝。

条款见《个人信息保护法》第 45 至 47 条,以现行文本为准。

## 交集

| 组合 | 必须同时满足什么 | 候选形态 | 判定 |
|---|---|---|---|
| a1 × b1 | 自动提取,而用户有权知道记了什么 | 记忆查看面板 | 存活候选的组成部分 |
| a3 × b2 | 系统动态更新,而用户有权更正 | 更正入口 | 存活候选的组成部分 |
| a2 × b3 | 绑定平台,而用户有权删除 | 删除 + 导出 | 存活候选的组成部分 |
| a5 × 无对应 | 主动打扰,而客户没有要求主动 | 打扰预算 | 砍:近域客户不为此付费 |
| a6 × 无对应 | 越用越粘,而客户想换供应商 | 迁移工具 | 砍:和被砍的「记忆可携带」重复 |

前三组指向同一个东西,不是三个候选项。

## 存活候选

**记忆权利中间层**:给已经接入记忆产品的 AI 中转商,包一层对外接口,让最终用户能查看、导出、删除自己被记下的内容,并附一份可外发的处理说明。

- 现在有人做吗:待查证。阿里云 Memory 是平台侧 API,面向开发者;mem0 一类开源库提供 delete,也面向开发者。面向「最终用户自助」的层没有见到具体产品名,这一维目前只能写到这个程度,算半过。
- 做的人卡在哪:平台方没有动机做导出,导出等于降低迁移成本;中转商不知道怎么向客户承诺,因为他们自己也不清楚记忆里存了什么。
- 两周能出什么:包一层 REST,只做查看、导出 JSON、删除三个端点,加一张一页的记忆处理说明。三天。
- 第一个客户是谁、从哪认识:已经在卖 AI 接入服务、且被客户问过「你们记了我什么」的中转商。来源是现有圈子,不是远域。

## 差集备选(未过四维,只登记)

- 记忆遗忘与衰减:偏好变了,旧记忆必须主动作废。现在没有产品给出用户侧的控制。
- 记忆跨 Agent 授权:一个助理的记忆能不能给另一个助理读,没有细粒度权限模型。
- 记忆归属:员工使用企业助理产生的记忆,归公司还是归个人,采购场景里没人敢先定义。

三条都写不出第一个客户,按规则不存活。

## 方法学检查

- 存活候选是否同质:本轮候选与 exp-01「模型指纹凭据」同族,都是可证明、可追溯。没有新家族。
- 是否全部落在实验者已有能力范围内:是。接口层加文档,是现有能力的直接延伸。
- 远域约束有多少条是编的:零。全部来自法条。
- 采样偏差:机器之心收录的是「已发布、有热度、有署名」的东西。它是署名池,不是机会池。

## 本轮结论

**一、被抢先的感觉来自采样面错位,不是事实。**

机器之心收录的每一条都已经有人署名、有团队、有发布。你的想法只要还没发布,就永远不会出现在那个池子里。所以拿它当对照,必然条条都像「我的想法被做了」——因为你在拿「有主的结果」去比「无主的念头」。

这一条比本轮任何候选都重要。它同时说明:这个平台唯一该被用的位置,是四维里的第一维(现在有人做吗),不是机会面。这与 DESIGN.md 规则二「热点只在一个位置有用」一致,本轮是它的又一次验证。

**二、拿热点当近域,撞出来的还是老家族。**

六个产品面给出的差集,最后收敛到「可证明、可追溯」,和 exp-01 同族。规则三(家族由近域决定)和规则四(轴向决定家族)都成立。

**三、真正的差集不在媒体上。**

媒体只报成功与上线,不报失败、不报卡点、不报「做完了没人用」。四维的第二维「做的人卡在哪」在公开信息里基本查不到。这个洞不是机器之心偷懒,是它的采样条件决定的:失败没有署名。要拿到这一维,只能去问人,不能去搜。

## 复跑:机器实跑

手工结论之外,用仓库管线原样跑了一遍。近域与远域落成约束文件,没有另写代码。

- 命令:`python -m collider run --config configs/exp05.json --out runs/exp05`
- 闸门:近域 6/6、远域 4/4 判为约束,零解析失败;a1、a5、b3 的轴向模型给不出
- 碰撞:24 对全部生成,去重后 22 条候选
- 四维:2 条 alive,20 条 draft

两条 alive:

| id | 组合 | 形态 |
|---|---|---|
| c002 | a1 × b2 | 可校验的凭据 |
| c010 | a3 × b2 | 可更正的界面 |

问题在形态本身:

1. c002 的「可校验的凭据」是训练集里 exp-01 的家族词。模型把「记忆更正」撞成了旧家族的词,说明碰撞训练样本(28 行,来自 exp-01 至 04)已经把它钉在凭据、留存、版本这三类上。
2. 20 条 draft 大量出现「强制」「超时处罚页」「强删除」「删除权限被冻结」。模型把合规理解成惩罚,不是产品形态。
3. 22 条里没有一条指向记忆可携带、遗忘衰减、跨 Agent 授权。这三条正是手工分析里真正空白的差集。

结论:机器反跑可用,但输出上限由训练样本决定。撞出来的仍是旧家族,与手工结论一致,区别是这次是实证而非推断。

改用力的方向因此明确:要撞出新家族,先补碰撞训练样本的轴向,而不是换远域。但这一步仍然只提高产量,不解决证据侧缺失——样本补完,第一个客户那一维照样是空的。

## 规则修订

无新增硬规则。本轮是对规则二、三、四的重复验证。
